# 08. MySQL 사용자 권한 관리

> **실습 예제 — 실제 실행 결과는 아직 확인하지 않았습니다.**

## 목표
사용자마다 DB에서 할 수 있는 작업을 다르게 설정하는 방법을 연습합니다.

## 실습 방법
1. 관리자 계정으로 MySQL에 접속합니다.
2. `audiolog_reader`라는 별도 계정을 만듭니다.
3. 이 계정에는 `audiolog` DB의 **SELECT(조회)** 권한만 부여합니다.
4. MySQL Workbench에서 새 연결을 만들어 `audiolog_reader` 계정으로 로그인합니다.
5. 회원 수를 조회해 정상 동작하는지 확인합니다.
6. 같은 계정으로 `INSERT`를 시도해 쓰기가 거부되는지 확인합니다.

모든 명령어는 [권한 관리 SQL](../sql/06_user_permissions.sql)에 **주석으로 보관**했습니다. 먼저 내용을 읽고 자신의 로컬 실습 DB에서 필요한 부분만 실행합니다.

## 예상 결과

| 테스트 | 예상 결과 |
|---|---|
| `SELECT COUNT(*) FROM audiolog.users` | 성공 |
| `INSERT INTO audiolog.users ...` | 권한 부족 오류 1142 |
| `SHOW GRANTS` | SELECT 권한 확인 |

위 표는 **예상 결과**입니다. 실제 DB에서 실행한 뒤 결과를 확인해야 완료된 실습으로 기록할 수 있습니다.

## 주의할 점
- 계정을 만들 때 예시 비밀번호를 반드시 변경합니다.
- 실습은 로컬 DB에서만 진행합니다.
- 앱에서 사용하는 계정은 필요한 권한만 갖도록 설정하는 것이 기본 원칙입니다.
- 새 계정에는 `root` 권한을 부여하지 않습니다.
