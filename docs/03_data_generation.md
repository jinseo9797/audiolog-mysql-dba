# 03. Python 데이터 생성

## 목적
인덱스 조회와 백업을 연습하기 위해 가상의 데이터를 많이 만들었습니다.

## 진행 방식
1. Python으로 회원과 콘텐츠를 만들었습니다.
2. MySQL에 저장된 **실제 회원 ID와 콘텐츠 ID**를 읽어 왔습니다.
3. 해당 ID를 이용해 청취 기록을 만들었습니다.
4. 청취 기록을 **5,000건씩 나눠** 저장했습니다.

한 번에 여러 행을 넣는 데 `executemany()`를 사용했습니다. 각 묶음이 성공하면 `commit()`으로 저장을 확정하고, 실패하면 아직 확정하지 않은 묶음은 `rollback()`으로 취소했습니다.

## 결과
| 데이터 | 건수 |
|---|---:|
| 회원 | 1,000 |
| 콘텐츠 | 100 |
| 청취 기록 | 100,000 |

생성한 청취 시간은 해당 콘텐츠의 전체 재생 시간을 넘지 않도록 했습니다.

## 배운 점
데이터를 여러 묶음으로 나눠 넣는 방법을 배웠습니다. 실행 도중 실패해도 **이미 저장을 확정한 묶음은 그대로 남습니다.** 다시 실행하면 현재 건수를 확인하고 부족한 수만 채웁니다.

단, 여러 프로그램이 동시에 데이터를 만드는 상황까지 처리하는 코드는 아닙니다.
