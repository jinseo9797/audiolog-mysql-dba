# 03. Python 데이터 생성

## 목표
실제로 존재하는 회원과 콘텐츠를 이용해 가상 청취 기록 10만 건을 생성했습니다.

## 생성 결과
| 테이블 | 건수 |
|---|---:|
| 회원 | 1,000 |
| 콘텐츠 | 100 |
| 청취 기록 | 100,000 |

## 진행 방법
1. Python으로 가상 회원과 콘텐츠를 생성했습니다.
2. MySQL에서 실제 `user_id`와 `content_id`를 읽어 왔습니다.
3. 청취 기록을 **5,000건씩** 나눠 `executemany()`로 저장했습니다.
4. 배치가 성공하면 `commit()`, 실패하면 아직 저장 확정되지 않은 배치를 `rollback()`했습니다.

청취 시간은 선택한 콘텐츠의 재생 시간을 넘지 않도록 만들었습니다.

## 배운 점
데이터를 나누어 넣으면 한 번에 다루는 양을 조절할 수 있습니다. 이번 코드는 중간 실패 시 이미 완료된 배치는 남고, 다시 실행하면 현재 저장 건수를 확인해 목표 건수까지 추가합니다. 여러 사람이 동시에 실행하는 상황까지 처리하지는 않습니다.
