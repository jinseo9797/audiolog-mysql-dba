# 08. MySQL 사용자 권한 관리

> **아직 실행하지 않은 실습 예제입니다.** 아래의 결과는 실제 측정값이 아니라 예상 결과입니다.

## 무엇을 하려고 하나요?
DB를 사용하는 사람마다 **할 수 있는 작업을 제한하는 방법**을 연습하려고 합니다.

예를 들어 데이터를 보기만 하는 계정은 조회는 할 수 있지만, 데이터를 추가하거나 수정할 수 없도록 설정합니다.

## 어떻게 실습하나요?
1. 관리자 계정으로 MySQL에 접속합니다.
2. `audiolog_reader`라는 새 계정을 만듭니다.
3. 새 계정에 `SELECT`(조회) 권한만 부여합니다.
4. Workbench에서 그 계정으로 다시 접속합니다.
5. 회원 수를 조회해 보고, 데이터를 추가하려고 할 때는 거부되는지 확인합니다.

**실습용 SQL:** [권한 관리 예제](../sql/06_user_permissions.sql)

> SQL은 실수로 실행되지 않도록 주석 처리했습니다. 실제 로컬 DB에서 필요한 부분만 주석을 해제해 실행해야 합니다.

## 예상 결과
| 테스트 | 예상 결과 |
|---|---|
| `SELECT`로 회원 수 조회 | 성공 |
| `INSERT`로 회원 추가 | 권한 부족 오류 1142 |
| 관리자 계정에서 `SHOW GRANTS` 확인 | 부여한 조회 권한 확인 |

## 배울 내용
관리자 권한을 모든 계정에 주는 대신, **필요한 작업만 허용하는 것**이 더 안전하다는 점을 확인하는 실습입니다.

실제로 실행하고 결과를 확인한 뒤에만 완료된 실습으로 표시할 예정입니다. 예시 비밀번호는 반드시 변경하고, 로컬 연습 DB에서만 실행해야 합니다.
